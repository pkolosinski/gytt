# Implementation plan index

Keep one task per file and list every task in this index.

| Number | Task | Status | Dependencies |
| ---: | --- | --- | --- |
| [number] | [title](task-[number]-[short-title].md) | (pending \| in progress \| done) | [linked task files] |

Each task file should use this schema:

```markdown
# Task [number]: [title]

**Status:** pending | in progress | done

**Depends on:** None | [linked task files]

**Description:** What must be done.

**Acceptance Criteria:**

- Conditions that must be met before marking the task done.
```
